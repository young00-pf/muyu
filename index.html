Class

무유의 도자 수업은 흙을 직접 만지며 손의 감각으로 형태를 만들어가는 시간입니다.

  • Regular Class
    정규 수업

    도자를 지속적으로 배우며 흙에 대한 이해를 깊게 쌓아가는 수업입니다.
    천천히 빚고, 느리게 완성하며 도자의 과정을 온전히 경험합니다.

    Regular Class
    정규 수업

    물레 성형과 핸드빌딩을 병행하며 기본적인 성형 과정과 흙의 성질을 차분히 익혀갑니다.
    수업은 각자의 속도와 손맛을 존중해 진행되며, 작업을 이어가는 과정 속에서 흙과 형태에 대한 이해를 쌓아갑니다.

  • Oneday Class
    일일 수업 - 핸드빌딩

    핸드빌딩 클래스는 흙을 손으로 직접 빚어 형태를 만들어가는 수업입니다. 흙을 손으로 직접 빚으며 흙의 질감과 형태를 느낄 수 있습니다.

    Oneday Class
    일일 수업 - 핸드빌딩

    수업은 각자의 속도와 손맛을 존중해 진행되며, 작업을 이어가는 과정 속에서 흙과 형태에 대한 이해를 쌓아갑니다.

  • Oneday Class
    일일 수업 - 물레성형
